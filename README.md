# Katarsis для Android

Неофициальный клиент Telegram: сохраняет удалённые и отредактированные
сообщения, умеет режим призрака — и не отправляет наружу ничего о вас.

> **Изменённая версия.** Katarsis — форк [Nagram](https://github.com/NextAlone/Nagram)
> (который сам является форком Telegram для Android). Изменения внесены aevornyx
> в июле–августе 2026 года; перечень — в [NOTICE.md](NOTICE.md).
>
> Katarsis не связан с Telegram Messenger LLP и не является официальным клиентом.

## Скачать

Готовые сборки — в разделе
[Releases](https://github.com/aevornyx/katarsis-android/releases/latest).

| Что скачивать | Кому |
|---|---|
| `Katarsis-…-arm64-v8a.apk` | почти всем — современные телефоны |
| `Katarsis-…-armeabi-v7a.apk` | старые устройства |

Если не знаете, какой у вас процессор, берите **arm64-v8a**: он подходит
подавляющему большинству телефонов, выпущенных после 2015 года.

Android заблокирует установку файла, скачанного браузером, — потребуется
разрешить установку из неизвестных источников. Это обычная защита системы,
а не признак проблемы со сборкой.

Контрольные суммы SHA-256 указаны в описании каждого выпуска: по ним можно
убедиться, что скачан именно наш файл.

## Чем отличается от исходного форка

Katarsis собран на основе [Nagram](https://github.com/NextAlone/Nagram) и
отличается прежде всего тем, чего в нём **нет**.

**Наружу не уходит ничего.** Из сборки вырезаны Sentry и Firebase Crashlytics.
Sentry отправлял на чужой сервер не только падения, но и ANR-дампы стека
потоков и скриншоты экрана в момент сбоя. Проверено в готовом APK: упоминаний
этих библиотек — ноль.

**Нет рекламы чужого проекта.** Исходный форк при открытии списка чатов
предлагал подписаться на свои каналы. Убрано.

**Переименовано целиком.** Не только название на экране: пакеты, классы, имена
ресурсов, функции JNI. Внутри не осталось следов исходных проектов — кроме
идентификаторов, которые хранятся на устройстве и смена которых стёрла бы
пользовательские данные (подробности в NOTICE).

## Возможности

- сохранение удалённых сообщений прямо в переписке, с пометкой и приглушением;
- сохранение одноразовых фото, кружков и голосовых — включая пришедшие в
  закрытый чат;
- история правок сообщений;
- полный режим призрака: не отмечать прочитанным, не показывать «в сети»,
  не отправлять «печатает»;
- сохранение медиа из чатов с запретом пересылки;
- работа в фоне без Google-сервисов.

## Сборка

Нужны JDK 17, Android SDK, NDK `27.3.13750724`, MSYS2 (make, nasm, yasm, patch).

**1. Ключи Telegram API.** Получить на
[core.telegram.org](https://core.telegram.org/api/obtaining_api_id) и вписать
в `local.properties` в корне проекта:

```properties
sdk.dir=C:/Users/имя/AppData/Local/Android/Sdk
TELEGRAM_APP_ID=1234567
TELEGRAM_APP_HASH=ваш_хеш
KEYSTORE_PASS=пароль
ALIAS_NAME=псевдоним
ALIAS_PASS=пароль
```

Путь к SDK — **через прямые слэши**. Файл в `.gitignore` и в репозиторий
не попадает. Чужие ключи использовать нельзя: их выдают под конкретный
аккаунт, и Telegram блокирует аккаунты, замеченные на чужом `api_id`.

**2. Ключ подписи.** Создать свой и положить рядом:

```bash
keytool -genkeypair -v -keystore TMessagesProj/release.keystore \
        -alias katarsis -keyalg RSA -keysize 4096 -validity 10000
```

Ключ в репозиторий не попадает (`*.keystore` в `.gitignore`). **Не теряйте
его** — обновления подписываются только им, иначе пользователям придётся
переустанавливать приложение с нуля.

**3. Сборка:**

```bash
./gradlew :TMessagesProj:assembleDebug
```

Собираются сразу оба ABI. Выход — `TMessagesProj/build/outputs/apk/debug/`.

Собирается только debug-конфигурация: задачи NDK для release в проекте
отключены, поэтому нативные библиотеки строятся лишь в debug. Функционально
такая сборка полноценна.

## Push-уведомления

По умолчанию используется Firebase. Файл `google-services.json` в репозитории
принадлежит **исходному проекту**, поэтому перед публикацией своей сборки
заведите свой проект в Firebase Console и замените файл — иначе токены ваших
устройств регистрируются в чужом проекте.

Альтернативы: UnifiedPush со своим сервером или полный отказ от push —
уведомления тогда приходят по постоянному соединению.
